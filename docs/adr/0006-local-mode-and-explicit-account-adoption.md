# Preserve local mode and require explicit account adoption

BetterWeekToDo remains fully usable in local mode without an account. When a local workspace contains data, sign-in requires the user to merge it into the selected account, delete it and use the account data, or cancel; the client never silently uploads or discards local data and never offers to replace the account wholesale. This preserves private local use while preventing sign-in from becoming an accidental destructive synchronization operation.
