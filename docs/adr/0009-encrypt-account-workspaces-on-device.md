# Encrypt account workspaces on every device

Every account-bound, explicit Offline, and local workspace is encrypted at rest using vetted platform cryptography and a per-installation key. Native clients protect that key with the operating-system credential store, while the web client uses a non-extractable Web Crypto key with its weaker browser-security limitations documented. Authorization expiry removes usable account-key access while retaining ciphertext for reauthentication; logout, account switch, or confirmed revocation deletes both account key material and workspace data. Local mode requires no account, while an optional PIN or biometric app lock can provide meaningful user-facing access control. This makes Locked a data-access boundary rather than only a user-interface state.
